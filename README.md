# Наследие Ржавчины и Магии
[Русский](README.md) · [English](README.en.md)

**GitHub About / English:** Just for fun, as Torvalds put it: an experiment toward an interesting RPG. Not yet what I want, but the ideas keep coming, and I keep at it.
**Описание GitHub / Русский:** Just for fun, как говорил Торвальдс: эксперимент ради интересной RPG. Пока не то, что хочется, но мыслей много, и я всё равно её делаю.

Just for fun. Как говорил Линус Торвальдс — просто потому что хочется. Сейчас это эксперимент: ещё не та RPG, которую хочется увидеть, мыслей много и даётся трудно, но цель всё та же — интересная ролевая игра.

Браузерная кооперативная RPG (1–8 игроков) в постапокалиптическом мире, где технологии смешаны с магией. Полная концепция — в [GDD.md](GDD.md), история изменений — в [CHANGELOG.md](CHANGELOG.md).

**Статус:** шаг 1 (фундамент) в работе — готовы сервер, аккаунты, роли, вход и создание персонажа.

**Посмотреть всю технику:** откройте [галерею с картинками](artifacts/vehicles/index.html) двойным щелчком — 26 моделей, каждая в восьми ракурсах. При запущенном сервере доступен [интерактивный просмотр](http://localhost:3333/vehicle-gallery.html?id=helicopter): вращение корпуса и башен, увеличение, качество, человек для сравнения масштаба и сохранение PNG.

**Большой кооперативный мир:** U у метки «Переход» загружает соседний регион. До восьми игроков могут находиться в разных регионах и подземельях одновременно. Машина перевозит водителя, пассажиров и сидящих внутри спутников; точка прибытия учитывает весь корпус и занятые места. F2 открывает журнал с регионом и направлением к сюжетной цели; на экране есть указатель. Области создаются по мере посещения, пустые сохраняются и выгружаются.

**Ремонт и поведение:** Y позволяет сесть даже в разбитую машину: при наличии седока она бесплатно восстанавливает 0,25% прочности в секунду, двигатель включается выше 25%. O расходует автозапчасти и чинит сразу, до 100% при достаточном запасе. Герой, спутники, жители и отступившие враги медленно лечатся; погибшие автоматически не оживают от регенерации. T рядом с разумным противником — переговоры, перемирие или предложение идти следом как почитатель; Shift+T сохраняет прежнее привлечение спутника. Почитатели не занимают места команды. Боссы, их свита и волки не сдаются. Группы могут обходить с флангов и отвлекать.

**Журнал для диагностики:** в панели администратора F10 → «Сервер» включаются уровни trace/debug/info/warn/error/fatal и при необходимости запись копии в `log/`. Изменения применяются сразу; ошибки посадки и команды транспорту также отмечаются в серверной консоли.

## Запуск

Требуется **Node.js 18+** (зависимость одна — `ws`).

**Windows:** если на компьютере ещё нет Node.js, дважды щёлкните `install-deps.bat`: он скачает официальный Node.js LTS (18+) и установит зависимости по `package-lock.json`. Затем запустите `start.bat` — сервер откроется на `http://localhost:3333`. `start.bat` также предложит установку, если Node.js не найден. Другой порт: `start.bat 3100`. Справка: `start.bat --help`.

**Переносимый ZIP-релиз:** запустите `build-release.bat` (или `npm run build:zip`). Готовый ZIP появится в отдельной папке `releases\RustAndMagic-v<версия>-build-<дата-время>\`; версия также записывается в `BUILD_VERSION.txt`, рядом создаётся SHA-256. После каждой успешной сборки остаются три самых новых релиза, остальные удаляются. В архив входят исходники, документация, установщик Node.js, пакетный запуск, скрипты сборки и production-зависимости. На новом компьютере распакуйте ZIP и запустите `install-deps.bat` (он поставит Node.js, если нужно), затем `start.bat`. Игровые сохранения, `config.json`, секреты, временные файлы, `.git` и локальный `node_modules` в исходном проекте в архив не копируются. После переноса сервер создаст новую папку `data`; сохранения переносите отдельно, если они нужны.

**Перезапуск в Windows:** дважды щёлкните `restart.bat`. Он остановит предыдущий сервер выбранной папки данных, сохранит игроков и запустит новый. Аргументы те же: `restart.bat 3100` или `restart.bat --data D:\rpg-data`. Уже запущенная старая версия без канала перезапуска будет завершена принудительно один раз; последующие перезапуски сохраняют игроков перед остановкой.

**Вручную:**

```bash
npm install
npm start                       # http://localhost:3333
npm start -- --port 3100        # другой порт
npm start -- --help             # все параметры
```

Остальные игроки в локальной сети подключаются по адресу `http://<IP-компьютера>:3333` (может понадобиться разрешить порт в брандмауэре). Подробнее — раздел «Игра по сети» ниже.

### Игра по сети

- **Сервер слушает все сетевые карты** (`host` = `0.0.0.0` по умолчанию; только этот компьютер — `--host 127.0.0.1`). При запуске он печатает адреса для друзей, например `http://192.168.1.5:3333` — их и сообщите.
- **Локальная сеть (LAN, Wi-Fi):** друзья открывают напечатанный адрес в браузере. Если не открывается — разрешите Node.js в брандмауэре Windows (при первом запуске Windows спрашивает; иначе «Брандмауэр Защитника Windows → Разрешить приложение» или правило для TCP-порта 3333). Проще всего — запустить `firewall-allow.bat` (или `firewall-allow.bat 3334` для другого порта): он сам запросит права администратора и добавит правило для всех профилей сети. Частая причина: Windows разрешила Node.js только для «общественных» сетей, а домашняя сеть отмечена как «частная». Пошаговый вариант — `lan-setup.bat`: покажет адреса ПК, спросит IP-адрес сервера и порт (Enter — предложенные), добавит то же правило (и по желанию разрешит ping), проверит, что сервер отвечает, и подскажет, что проверить на другом ПК (`Test-NetConnection IP -Port 3333`).
- **Через интернет с пробросом порта:** на роутере перенаправьте внешний TCP-порт 3333 на IP вашего компьютера (раздел «Port Forwarding» / «Виртуальные серверы»). Друзья заходят по `http://<ваш-внешний-IP>:3333` (внешний IP — на сайте вроде 2ip.ru). Не работает за «серым» IP провайдера (CGNAT) — тогда VPN ниже.
- **Без проброса — виртуальная локальная сеть:** **Radmin VPN** или **ZeroTier** (бесплатно). Все ставят программу и входят в одну сеть; сервер напечатает адрес вида `http://26.x.x.x:3333` (Radmin) или `http://10.x.x.x:3333` (ZeroTier) — его и открывают друзья.
- **Голосовой чат** идёт напрямую между браузерами (WebRTC). В одной сети и через VPN он работает сразу; через интернет нужен STUN (настройка `game.voiceStunUrls`), а за строгим NAT — свой TURN-сервер (`voiceTurnUrl`, `voiceTurnUser`, `voiceTurnPass`). Микрофон браузер даёт только на `localhost` или по HTTPS — для игры по IP включите в Chrome флаг `chrome://flags/#unsafely-treat-insecure-origin-as-secure` с адресом сервера.
- **Надёжность:** при обрыве связи клиент сам переподключается и продолжает с того же места; сервер отвечает на пинги и закрывает «мёртвые» соединения; ошибка в обработке одного сообщения не роняет сервер (журнал, счётчик ошибок в оверлее F8), при аварии мир сохраняется (`crashSafe`). Сжатие WebSocket — `wsCompress`.
- **Трафик:** сервер шлёт каждому игроку только сущности в радиусе `game.netViewRadius` (40 клеток) и только изменения (`game.netDelta`, полный кадр раз в `game.netKeyframeSec` с); враги дальше `game.aiSleepRadius` от игроков «спят». Замер: ~57 → ~18 КБ/с на игрока (средний мир, 160 врагов).

Если порт занят, сервер сообщит об этом и предложит другой; флаг `--auto-port` сам займёт следующий свободный.

## Настройки

Все настройки собраны в одном модуле (`server/config.js`) и имеют значения по умолчанию. Приоритет:

1. флаги командной строки: `--port`, `--host`, `--data <папка>`, `--config <файл>`, `--auto-port`, `--open`, `--set ключ=значение` (любая настройка);
2. переменные окружения: `PORT`, `HOST`, `DATA_DIR`, остальные — `RM_<КЛЮЧ>` (например `RM_SESSION_TTL_DAYS`, `RM_GAME_START_POINTS`);
3. файл `config.json` в корне проекта (скопируйте `config.example.json`; сам `config.json` не хранится в git);
4. значения по умолчанию (порт **3333**).

Полный список настроек с описаниями — `npm start -- --help`. Среди них: срок сессии, лимиты защиты от перебора, длина имени и пароля, стартовые очки характеристик, число персонажей и миров на аккаунт, размеры карт, скорость героя, пределы масштаба (`game.zoomMin` / `game.zoomMax` / `game.zoomDefault`), размер клетки на экране, период сохранения позиции, параметры кэша рендера, предел игроков в мире, частота тиков сервера, задержка интерполяции, параметры переподключения и WebSocket, ограничения чата, ячейки и переносимый вес (`game.baseSlots`, `game.baseCarryKg`, `game.carryPerStrength`), стартовый набор (`game.startingKit`) и др. Настройки группы `game.*` передаются клиенту через `/api/config`.

### Файловый журнал сервера

Журнал выключен по умолчанию. В `config.json` включите `logging.enabled`; файлы будут создаваться в `log/server-ГГГГ-ММ-ДД.log` рядом с игрой. Уровни `trace`, `debug`, `info`, `warn`, `error`, `fatal` включаются отдельно через `logging.levels`; все они выбраны по умолчанию, когда журнал включён. Изменения применяются после перезапуска сервера. Пример настройки через запуск: `npm start -- --set logging.enabled=true --set logging.levels.debug=false`. Записываются серверный вывод, ошибки, HTTP API-запросы, а также входы и выходы игроков из миров. Логи не содержат тела запросов.

## Администратор

- **Первый зарегистрированный аккаунт автоматически становится администратором.**
- Назначить или снять администратора из консоли (можно при работающем сервере):

  ```bash
  node server/tools/make-admin.js <имя>            # выдать роль admin
  node server/tools/make-admin.js <имя> --revoke   # вернуть роль player
  node server/tools/make-admin.js --help           # справка
  ```

- Проверить баланс после правки врагов или настроек — симулятор боя по формулам игры:

  ```bash
  npm run balance                                   # эталонные бои: победы, время, остаток здоровья
  npm run balance -- --runs 200 --set game.enemyDamagePerLevel=0.08
  node server/tools/balance.js --help               # справка
  ```

- **Голос (шаг 18):** вкладка «Голос» в панели ГМ — кто в каких голосовых каналах, заглушить голос игрока на срок или навсегда с причиной (сервер рвёт его соединения и больше не соединяет), вернуть голос, журнал голоса; кнопка «Заглушить голос» есть и на вкладке «Игроки». API: `POST /api/admin/voice/list`, `/api/admin/voice/mute { username, minutes?, reason? }`, `/api/admin/voice/unmute { username }`; действия — в журнале администратора (`voice-mute`, `voice-unmute`).
- **Семья (шаг 17):** вкладка «Семья» в панели ГМ — по логину игрока: члены семьи (добавить, убрать, приглашение Патриарха), отношения с жителями (симпатия, стадия, забыть); API `POST /api/admin/family/list { username, character? }`, `/act { username, character?, act: rel|relDel|add|remove|invite, key?, affinity?, stage?, kind?, name?, gender?, role?, age?, level?, id? }`.
- **Задания и фракции (шаг 16):** вкладка «Задания» в панели ГМ — сюжет мира, выдать сюжетное задание, завершить или сбросить взятое (или всё), репутация героя у фракции, концовка; API `POST /api/admin/quests/list { worldId }`, `/act { worldId, act: grant|complete|reset|ending|faction, id?, username?, character?, ending?, faction?, value? }`. Команды `/ending игрок [destroy|rule|ally|unite|family|любое]` (сюжетная — завершает историю мира, иначе только отметка герою) и `/slay [all]` (сразить врагов от своего имени — цели заданий, репутация).
- **Поселения (шаг 15):** вкладка «Поселения» в панели ГМ — репутация героя, обновить товар, отстроить, набег; API `POST /api/admin/settlements/list { worldId }`, `/act { worldId, sid, act: rep|restock|repair|raid, username?, character?, value?, count? }`.
- **Техника (шаг 14):** вкладка «Техника» в панели ГМ — создать рядом (целую или обломок, свою), починить, заправить, убрать; API `POST /api/admin/vehicles/list { worldId }`, `/spawn { def, wreck?, own?, username? }`, `/act { id, op: repair|refuel|remove }`.
- **Уровни (шаг 13):** команда в чате `/level -2` (по z), `/level b0.2` (по ключу входа и номеру), `/level ground` — телепорт на уровень; `POST /api/admin/teleport { level, x?, y?, username? }`; «К нему» переносит и на другой уровень того же мира.
- **Панель ГМ** — в мире клавиша **F10** или кнопка 🛡 (видна только администратору; сервер проверяет роль на каждом запросе). Панель сбоку, карта остаётся доступной. Сверху — режим бога: невидимость (игроки и враги вас не видят), неуязвимость, полёт (**Alt + щелчок** по карте — мгновенный перенос, даже через воду и горы). Вкладки:
  - **Игроки** — все аккаунты, кто где в сети; к игроку, призвать к себе, выгнать, бан на срок (15 мин / 1 ч / 1 день / 7 дней / навсегда) с причиной, разбан, роль;
  - **Персонажи** — характеристики (от 1), уровень, опыт, здоровье, мана, выносливость, очки, смерти любого героя; выдать / забрать предмет (поиск по каталогу, количество);
  - **Спавн** — враг, босс или предмет (поиск), количество, рядом со мной / по щелчку на карте / у игрока (враги сразу нападают на него);
  - **Сообщения** — личное сообщение (сейчас или отложенное — дойдёт, когда игрок войдёт), объявление в этот мир или всем (сейчас, позже, с повтором);
  - **События** — список, добавить (супер-босс, главарь, дракон, орда, двойной лут на время, объявление, сообщение), запустить, отменить;
  - **Журнал** — действия администраторов с фильтрами (действие, цель, администратор, текст) и страницами;
  - **Мир** — все миры и их настройки, кто в сети, «Сохранить» сейчас, резервные копии (создать; восстановить — `node server/backup.js restore` при остановленном сервере).
- Бан: бессрочный или временный, с причиной. Заблокированный игрок при входе видит причину и оставшееся время; после истечения срока вход открывается сам.
- Команды в чате мира (только администратор): `/spawn <враг> [кол-во]` — создать врагов рядом (id или название из справки «Враги»; они сразу нападают на вас, даже у точки появления), `/kill` — убрать врагов рядом (`/kill all` — всех в мире, `/kill <игрок>` — убить игрока, со штрафом за смерть), `/heal [игрок]` — вылечить, `/setlevel <игрок> <уровень>` — задать уровень (очки характеристик пересчитываются), `/ending <игрок> [концовка]` — отметить концовку (открывает «Новую игру+»), `/event list | add <тип> [через_мин] [каждые_мин] [текст] | run <id> | remove <id>` — игровые события (см. ниже).
- Все действия администратора пишутся в `data/admin-log.jsonl`.

### Сохранение

Всё сохраняется само: герой — при изменениях (вещи, опыт, позиция каждые `savePositionSec`), состояние мира — живые враги (и главари со свитой) с уровнем и здоровьем, турели, мины, таймер орд — каждые `autosaveSec` секунд (30), когда мир покидает последний игрок и при остановке сервера (Ctrl+C). Предметы на земле хранятся отдельно и тоже переживают перезапуск. Когда в мир снова кто-то входит, враги стоят на прежних местах. Владелец мира может сохранить всё сразу кнопкой **«Сохранить»** в меню Esc (не чаще раза в `game.manualSaveCooldownSec` секунд). Файлы пишутся атомарно (сначала во временный файл), так что обрыв питания не оставит полузаписанный файл.

### Герой в файле

На экране «Ваши персонажи» кнопка **«В файл»** скачивает героя JSON-файлом, **«Загрузить из файла»** возвращает. Файл подписан секретом сервера (`data/secret.key`, создаётся сам — не публикуйте его):

- свой файл (этот сервер, этот аккаунт, файл не изменён) возвращает героя целиком — если такого героя сейчас нет в списке и он не менялся между сохранением файла и удалением; один файл — один раз (иначе вещи удваивались бы);
- чужой, с другого сервера или изменённый файл — по настройке `characterImportForeign`: `appearance` (по умолчанию: только имя и внешность, герой 1-го уровня), `full` (весь герой после строгой проверки: уровень и опыт, очки характеристик по уровню, известные предметы, размер стопок, прочность, магазины, слоты), `reject` (отказ).

Занятое имя можно сменить при загрузке. Предел героев на аккаунт действует и здесь.

### «Новая игра+»

Герой, прошедший игру, отмечен концовкой (`endings` в записи героя; сюжетные концовки шага 16 — «Конец тирана», «Властелин пустоши», «Правая рука», «Мир пустоши», «Семья» — вызывают `markEnding` из `server/ngplus.js` всем игрокам мира, а вышедшим участникам — при следующем входе; администратор — `/ending <игрок> [концовка]`). У такого героя при создании мира есть галочка «Новая игра+» (`POST /api/worlds` с `newGamePlus: true, characterId`): мир получает поле `ngPlus { round, characterId, characterName, baseId }`, база аккаунта переходит, враги слабее — здоровье × `game.ngPlusEnemyHpFactor`, урон × `game.ngPlusEnemyDamageFactor` (0.75). Концовки из чужого файла героя не переносятся.

### Игровые события

`server/events.js` — ядро событий для будущей панели ГМ: события хранятся в `data/events.json` (переживают перезапуск), срабатывают по расписанию (проверка каждые `eventCheckSec` секунд) или сразу по команде администратора. Типы: `superboss` — супер-босс «Железный Патриарх» со свитой появляется в `game.eventSpawnDist` клетках от случайного игрока и идёт на него (сам он в мире не появляется — только так или `/spawn`); `boss` — главарь банды (`enemy` — какой, иначе случайный); `horde` — орда зомби; `announce` — объявление; `dragon` — нападение дракона; `doubleloot` — двойной лут на `durationMin` минут (`game.eventLootMultiplier`); `message` — личное сообщение `target` (дойдёт, когда он войдёт в мир). Событие может быть в одном мире или во всех (`worldId` не задан), разовым или с повтором (`everyMin`, не чаще `eventMinIntervalMin`). Разовое событие ждёт, пока в мире появятся игроки. Пример в чате: `/event add superboss 30` — супер-босс через 30 минут в этом мире; `/event add all:horde 0 120` — орда во всех мирах каждые 2 часа. Всё пишется в журнал администратора. Пределы: `eventMaxScheduled`, история — `eventHistory`.

### Резервные копии

Сервер делает копию папки данных при каждом запуске (`backupOnStart`, до обновления форматов файлов) и каждые `backupIntervalMin` минут (60); хранятся последние `backupKeep` (10) в папке `backupDir` (по умолчанию рядом с данными — `data-backups/`). Пока сервер работает, в `data/` лежит метка `server.lock`.

```bash
node server/backup.js list                 # список копий
node server/backup.js create before-update # копия сейчас (с меткой)
node server/backup.js restore latest       # восстановить последнюю (сервер должен быть остановлен)
node server/backup.js --help               # справка
```

Перед восстановлением текущие данные сами сохраняются в копию `…-before-restore`, так что откат можно отменить.

### Миры

- Настройки генератора: название, **сид** (случайный по умолчанию, кнопка 🎲; его можно скопировать и передать другу — тот же сид даёт ту же карту), размер (малый / средний / большой / огромный — размеры в настройке `game.worldSizes`), форма (квадрат, длинный путь, круг, овал, хаос или острова), плотность врагов, частота зомби-орд, число драконов и выживание.
- Миры хранятся на сервере в `data/worlds/`, принадлежат создавшему аккаунту; в списке — свои миры и чужие, к которым вы присоединились.
- **Совместный доступ:** владелец открывает мир («Открыть мир») и создаёт код приглашения; друг вводит код в поле «Присоединиться по коду» — мир появляется у него в списке как «чужой мир». В закрытый мир может войти только владелец. «Новый код» заменяет старый, «Убрать код» отключает приглашения; участник может «Покинуть» чужой мир. Длина кода и предел участников — настройки `game.inviteCodeLength`, `game.maxWorldMembers`.
- Карта генерируется одинаково на сервере и в браузере (`shared/worldgen.js`); сервер хранит только параметры и контрольную сумму.
- Биомы: море / озеро и река (герой может пересечь их вплавь медленно и с расходом выносливости), пустыня, пустошь, лес, руины города, предгорья (медленно), горы (непроходимы пешком), поселения; точка появления — на суше. Драконы, летающие сеты и транспорт с полётом пересекают воду и горы. Поле уровня `z` уже есть в данных (под будущие 15 уровней).
- Позиция героя сохраняется для каждого мира отдельно: периодически (`game.savePositionSec`) и при выходе; при повторном входе вы окажетесь там же.

### Совместная игра

- До **8** игроков одновременно в одном мире (`game.maxPlayers`, верхний предел 8); каждый — своим персонажем. Все игроки союзники против мира: PvP и дружественный урон отключены сервером, включая старые миры. Другие игроки видны фигурами в цветах их персонажей с именами, на миникарте — голубыми точками; счётчик 👥 под миникартой.
- При создании мира отдельно выбираются форма и водоёмы: квадрат, прямоугольник, круг, овал, длинный путь, хаос, острова или материк; суша без островов, озёра, море вокруг материка или архипелаг. Круглая и овальная игровая область ограничивает также пловцов и летунов. Старые карты без поля `waterMode` сохраняют прежний алгоритм.
- Соединение — WebSocket на том же порту (`/ws`, настройка `wsPath`), вход по сессии аккаунта. Заблокированный аккаунт не впускается, а если бан наложен во время игры — отключается сразу (при бане через API) или при перепроверке сессий (`wsBanCheckSec`).
- **Движение авторитетно на сервере:** клиент отправляет намерения — путь по клеткам (щелчок) или направление (WASD); сервер проверяет путь общим кодом (`shared/movement.js`: соседние проходимые клетки, без срезания углов, предел длины), двигает героя с учётом местности, проверяет каждый шаг и рассылает позиции с частотой `game.tickRate`. Клиент сразу предсказывает своё движение и сверяется с сервером; других игроков рисует с интерполяцией (`game.interpDelayMs`).
- Позиции сохраняет сервер: периодически, при выходе, при обрыве связи и при остановке сервера (Ctrl+C).
- При обрыве клиент сам переподключается с нарастающей задержкой (`game.reconnectBaseMs` … `game.reconnectMaxMs`, до `game.reconnectMaxAttempts` попыток); вход тем же аккаунтом в другой вкладке отключает первую.
- Настройка `game.requireOwnerOnline`: гости входят, только пока в мире владелец.

### Чат

- **Enter** — ввод сообщения всем в мире; щелчок по имени в чате — личное сообщение. Окно скрывается кнопкой 💬 или клавишей **L** (счётчик непрочитанных).
- Команды: `/w имя текст` — личное (имя героя или аккаунта, имя с пробелом — в кавычках; синонимы `/ш`, `/лс`, `/msg`), `/r текст` — ответить, `/who` — кто в мире, `/help` — список команд, `/announce текст` — объявление администратора во все миры; `/give игрок предмет [кол-во]` и `/take игрок предмет [кол-во]` — выдать и забрать предмет (только администратор; предмет — id или название).
- Каналы выделены цветом: всем в мире, личные, системные (вход/выход, ответы на команды), объявления администратора (золотым и баннером вверху экрана); сообщения администратора помечены 🛡.
- Сервер обрезает управляющие символы и экранирует HTML; длина сообщения (`game.chatMaxLength`), частота (`game.chatRateCount` за `game.chatRateWindowSec`) и история при входе (`game.chatHistory`, без личных) — настройки. Объявления можно отправлять и через API (`POST /api/admin/announce`) — заготовка для панели администратора; они пишутся в журнал действий.

| POST | `/api/admin/unban` | админ | `{ username }` |
| GET | `/api/admin/bases` | админ | `{ bases: [{ id, name, ownerId, ownerName, placed, structures, updatedAt }] }` — все базы |
| POST | `/api/admin/bases/remove` | админ | `{ id }` — удалить базу (со всеми постройками); пишется в журнал |
| POST | `/api/admin/recipes/give` | админ | `{ username, character?, recipe }` — научить рецепту (`recipe: 'all'` — всем) → `{ character, recipes }`; пишется в журнал |
| POST | `/api/admin/companions/list` | админ | `{ username, character? }` → `{ slots, shrinker, online, list }` — спутники героя |
| POST | `/api/admin/companions/give` | админ | `{ username, character?, def, level? }` — выдать спутника (есть место — рядом, иначе в контейнер); пишется в журнал |
| POST | `/api/admin/companions/spawn` | админ | то же, но спутник сразу призван рядом с героем (герой должен быть в мире); пишется в журнал |
| POST | `/api/admin/spells/list` | админ | `{ username, character? }` → `{ spells, power, all }` — заклинания героя и весь каталог |
| POST | `/api/admin/spells/teach` | админ | `{ username, character?, spell }` — научить заклинанию (`spell: 'all'` — всем; требования не проверяются; герой в сети — сразу); пишется в журнал |
| POST | `/api/admin/spells/remove` | админ | `{ username, character?, spell }` — стереть заклинание (и с панели 1–0; `'all'` — все и сила убитых магов); пишется в журнал |
| POST | `/api/admin/companions/remove` | админ | `{ username, character?, id }` — убрать спутника; пишется в журнал |
| POST | `/api/admin/items/give` | админ | `{ username, character?, item, count? }` — выдать предмет (`item` — id или название; `character` — id или имя, можно не указывать, если персонаж один) → `{ character, item, count }`; пишется в журнал |
| POST | `/api/admin/items/take` | админ | то же — забрать (сколько есть, не больше `count`) |
| POST | `/api/admin/announce` | админ | `{ text, worldId? }` → `{ rooms, players }` — объявление в чат всех активных миров или одного |

Авторизация: заголовок `Authorization: Bearer <token>`.

### WebSocket (`/ws`)

Сообщения — JSON с полем `t`. Клиент сначала отправляет `{ t: 'hello', token, worldId, characterId }`, сервер отвечает `welcome` (игроки в мире) или закрывает соединение с кодом из `shared/protocol.js` (4001 — сессия недействительна, 4003 — бан, 4004 — нет мест, 4005 — вход из другой вкладки, 4006 — нет доступа к миру, 4008 — владелец не в игре, 4010 — перезапуск сервера); перед закрытием приходит `{ t: 'kicked', code, message }`.

## Правила проекта

1. **Никаких «зашитых» значений.** Любая настройка (порт, адрес, папка данных, срок сессии, лимиты защиты от перебора, стартовые очки и т. п.) имеет значение по умолчанию и переопределяется через `config.json`, переменную окружения или флаг командной строки. Все настройки — в одном модуле `server/config.js`.
2. **Справка у каждой команды.** Любая точка входа командной строки (сервер, `make-admin.js`, любые будущие инструменты, `start.bat`) поддерживает `-h` / `--help` со списком всех параметров на русском. Неизвестный флаг — сообщение об ошибке и справка.
3. **Справка и подсказки в игре.** В игре есть подробный экран «Справка» (F1), а у элементов интерфейса — всплывающие подсказки на русском. Каждая новая функция добавляет свой раздел справки и подсказки.
4. **Каждая функция — с автотестами.** Тесты на встроенном `node:test` + `node:assert`, без новых зависимостей; `npm test` должен проходить перед коммитом.
5. **Документация актуальна.** README, CHANGELOG и статус дорожной карты в GDD обновляются в том же коммите, что и функция. Коммиты — небольшие и логичные.

## Недоделанное

### Кооператив, обмен и личные лавки

Лимит мира по умолчанию — **8 игроков**. Автолут распределяет предметы и стопки по очереди между живыми участниками рядом с включённым подходящим режимом сбора; фильтры, вес и вместимость учитываются.

Кнопка **«Обмен и лавки»** находится в панели героя слева сверху; дублируется в инвентаре. Прямой обмен вещами и крышками требует близости и подтверждения обоих участников. Изменение предложения сбрасывает подтверждения; выход, смерть, удаление или истечение времени отменяет сделку.

Личные лавки стоят в точке открытия независимо от владельца, сохраняются после выхода и перезапуска сервера. Цена задаётся за штуку. Навык **«Количество лавок»** повышается обычными очками характеристик и ограничен **5**; лимит общий для всех миров персонажа. Свернуть конкретную лавку или все сразу можно из раздела «Мои лавки / возвраты»; кнопка сворачивания всех также находится в панели героя. После распродажи лавка исчезает, выручка сохраняется. При сворачивании вещи и деньги переходят в возвраты: заполненная сумка не мешает закрыть лавку. Забор вещей и выручки снова проверяет вместимость. Валюта — крышки.

Настройки сервера: `game.shopItemsMax`, `game.shopBuyRange`, `game.tradeRange`, `game.tradeLifetimeSec`. Состояние лавок, возвратов и журнал незавершённой записи сделок хранятся в `commerce.json` в папке данных.

### Обновлённый рисунок и автобой

Кнопка с **домиком вверху справа** переключает четыре режима: **полный вид**, **низкие остатки**, **прозрачность внутри радиуса**, **сферический вырез с низкими основаниями внутри радиуса**. Радиус автоматически определяется максимальной дальностью надетого оружия, бортового оружия и изученных заклинаний. В меню **«Обзор окружения»** выбираются режим и прозрачность. Снаружи радиуса объекты целые; настройки сохраняются, столкновения и туман войны действуют во всех режимах.

Техника имеет правильные слои дальних и ближних колёс, танки — гусеницы и одну поворотную башню. Шагоходы сгибают ноги в постоянную сторону; шаги, выстрелы, магия, добыча, строительство и использование предметов имеют разные позы и эффекты.

Персонажи и существа рисуются в восьми направлениях; ходьба, ближний удар, стрельба и магия используют отдельные позы. Обновлены модели транспорта, окружение, снаряды и эффекты заклинаний.

Внизу справа, над автолутом, расположены независимые переключатели автобоя: **Ближний**, **Дальний**, **Магия**. Ближний бой подходит на дистанцию удара с учётом размера цели; дальний использует оружие в руках, его дальность и боеприпасы. Магия выбирает изученные заклинания с панели **1–0**, учитывает ману и откаты, применяет лечение и защиту по состоянию героя. Ручное перемещение временно приостанавливает автоматические действия. Переключатели сохраняются для персонажа в этом браузере.

Под миникартой находятся **−**, **+**, индикатор масштаба и **⟲** для возврата к обзору всей карты. Масштаб также меняется колёсиком; увеличенная миникарта следует за героем.

### Вещи спутников и трупы

В панели спутников кнопка **🎒** открывает надетые вещи и сумку (64 позиции). Вещи можно передавать из сумки героя и забирать обратно; для стопок есть поле количества. Переданное оружие и одежда надеваются автоматически, снятая вещь возвращается герою. Оружие меняет дальность и тип атаки, броня добавляет защиту. Боеприпасы спутник берёт из своей сумки; при их отсутствии использует базовую атаку. Книги и свитки в сумке дают доступ к автоматической магии с маной, временем чтения и откатами. Их можно забрать: доступ к подаренному заклинанию прекращается. Врождённые заклинания сохраняются.

Человекообразные враги и жители получают настоящие экземпляры одежды, оружия и вещей. При смерти их снаряжение выпадает дополнительно к случайному луту; вещи погибшего спутника также остаются на земле. Случайная добыча и шанс сетов есть при смерти любого персонажа, включая игрока; выпадение собственной сумки героя по-прежнему задаёт `game.deathDropItems`. Трупы игроков, врагов, жителей и окончательно погибших спутников сохраняются отдельно от ИИ и не участвуют в поиске пути.

`game.corpseLifetimeSec` задаёт срок хранения трупов: **60 секунд** по умолчанию, целое число **0–65536**, где 0 означает немедленное исчезновение. При запуске: `node server/index.js --set game.corpseLifetimeSec=60` либо поле в `config.json`. Во время игры настройка доступна в **Esc → Трупы** и **F9 → Я → Трупы**. Изменение общее для всех подключённых игроков и применяется сразу, включая уже лежащие тела. Время считается от смерти, поэтому сокращение срока сразу удаляет старые тела. Трупы входят в сохранение состояния мира; срок их жизни продолжает идти при отсутствии игроков. Растровый кэш рисунков ограничен по памяти, тела за пределами экрана не рисуются.

Враги возрождаются на очищенных участках через `game.enemyRespawnSec` (по умолчанию **90 секунд**, целое число 0–65536; 0 — при ближайшей проверке спавна). Активные участки рядом с игроками также получают случайные группы до общей численности `game.enemyPopulation` (по умолчанию **100**, целое число 0–250). Для каждого мира цель выбирается один раз с разбросом ±10%, затем дополнительно учитывается плотность мира. Безопасные зоны сохраняются, а неактивные участки очищаются как раньше. Настройки задаются при запуске через `node server/index.js --set game.enemyRespawnSec=90 --set game.enemyPopulation=100` или поля в `config.json`, а в игре меняются в **Esc → Враги** и **F9 → Я → Спавн**. Настройки применяются всем игрокам в мире сразу.

Глобальная сложность `game.difficulty`: `super_easy`, `easy`, `normal`, `medium`, `high`, `hard`, `hardcore` (по умолчанию `normal`). Она задаётся в `config.json` / `--set game.difficulty=hard` или меняется в меню игры, панели ГМ и чит панели; влияет на уровни, здоровье, урон и защиту врагов. На режимах от обычного вверх часть вещей героя случайно попадает в труп при смерти; шанс растёт с уровнем сложности. В `hardcore` теряются все вещи, а при возрождении герой возвращается к 1 уровню, базовым характеристикам и стартовому набору. Это сброс прогресса, а не удаление учётной записи.

Временные выпавшие предметы хранятся по `game.groundItemTtlSec` (по умолчанию **7200 секунд**, целое число 0–65536; 0 — удаляются при ближайшей проверке уборки сервера). Управление есть в **Esc**, панели ГМ и чит панели; параметр также задаётся при запуске и в `config.json`. Предметы, размещённые генератором в тайниках уровней, постоянные и этим таймером не удаляются. Предметы в сундуках и контейнерах не затрагиваются.

Трупы существ хранят их экипировку и сумку; тело игрока также принимает вещи, выпавшие при смерти, если включён `game.deathDropItems`. Рядом с телом можно забирать предметы и складывать свои вещи из сумки или экипировки. Всё, что осталось в теле при истечении срока хранения, исчезает вместе с ним.

### Возврат и перемещение панелей
Панели перемещаются за заголовок и остаются внутри экрана. Кнопки заголовка: − свернуть, □ развернуть, ▣ свернуть в значок, × закрыть. Нажатие на значок раскрывает окно. После закрытия постоянной панели (миникарта, спутники, герой, режимы атаки, автосбор, автобой, производительность) её значок возврата появляется сверху по центру. В меню «Восстановить все панели» возвращает исходную раскладку.

### Виды панелей
▣ скрывает панель в перемещаемый значок; нажатие на значок возвращает обычный вид. ▤ показывает обычный вид с содержимым, □ разворачивает на игровое поле, ❐ возвращает обычный вид. × закрывает окно. У спутников ☷ переключает компактный список с вертикальной прокруткой; полный список раскладывается по колонкам. H переключает полный/компактный список, а скрытую панель открывает. Если содержимое физически больше игрового поля, остаётся доступна прокрутка. Окна и значки ограничены границами игрового поля.

При перемещении панель или значок притягивается к соседним видимым панелям: стыковка краёв действует на расстоянии 18 пикселей, выравнивание ближайших углов — до 28 пикселей. При разной длине выравнивается ближайший верхний/нижний или левый/правый край. Чтобы отцепить панель, продолжайте тянуть её мышью. Соседние окна не двигаются; магнетизм не выводит окно за игровое поле.

Кнопки окна собраны справа в одинаковом порядке слева направо: скрыть в значок, весь экран/восстановить, обычный вид, компактный список (если предусмотрен), закрыть ×. Крестик всегда крайний справа. Значки возврата закрытых служебных панелей размещены отдельно снизу слева, над нижними кнопками, вместо центра поверх производительности.

Панель значков закрытых окон можно перетаскивать за ручку ⠿ слева или свободное место между значками. Она остаётся внутри игрового поля и притягивается к соседним панелям. Положение сохраняется для игрока; «Восстановить все панели» сбрасывает его.

### Исключённые союзники и контекстная справка
В панели спутников (H) есть отдельный список «Исключённые союзники» с расстоянием. Подойдите к живому бывшему спутнику и нажмите 🤝 или T: он возвращается без нового приручения, если есть свободный слот. Далёкий союзник виден в списке, но кнопка недоступна до подхода. Максимум команды — 11.

Задержите курсор на элементе интерфейса или объекте игрового поля: подсказка появляется через 450 мс, видна 5 секунд и открывает связанную страницу справки по нажатию. К подсказке можно перевести курсор. Для повторного показа отведите курсор и наведите снова. Подсказки предметов инвентаря и панели 1–0 используют тот же механизм.

F1 или ? открывает справку с меню категорий, подразделами и поиском по названиям и описаниям. Каталоги всех предметов, вариантов оружия и брони, сетов, заклинаний, врагов, жителей, характеристик, техники, построек и рецептов формируются из данных игры. Результаты поиска выводятся порциями по 60; кнопка ＋ показывает следующую порцию. Подсказка предмета/заклинания/врага открывает его конкретную статью, а кнопки управления — соответствующую механику.

В меню игры → «Доступность» галка «Подсказки включены» управляет подсказками интерфейса, инвентаря и игрового поля. Поле «Время показа подсказки, секунд» задаёт длительность от 1 до 65536 секунд; по умолчанию 5. Настройки применяются сразу и сохраняются отдельно для аккаунта в этом браузере. При отключении скрываются также обычные браузерные подсказки title; справка F1 остаётся доступна.

### Выбор и сохранение сложности
При создании мира есть обязательное поле «Сложность игры» с семью режимами; заранее выбран «Сверх лёгкая». Выбранное значение хранится в файле мира. Меню игры → «Сложность этого мира» → «Применить для всех» меняет уровень на лету для всех участников этого мира и его вертикальных уровней. Смена сохраняется сразу и переживает выход из игры и перезапуск сервера. Читы и панель ГМ внутри мира используют ту же настройку. Общая панель ГМ без выбранного мира может изменить сложность всех миров; общий выбор также сохраняется. На списке миров показывается их текущая сложность. Сложность выживания выбирается отдельно.

Пока подсказка видна, **F1** открывает связанный с ней раздел справки: переводить курсор на подсказку не требуется. Без видимой подсказки F1 открывает общую справку. Нажатие на саму подсказку также поддерживается.

Обновление управления справкой: подсказки больше не предлагают нажать на них и не перехватывают мышь. Пока подсказка видна, используйте F1; справка открывается поверх игровых окон. Обычный и компактный виды спутников показывают одного выбранного спутника из выпадающего списка, в том числе исключённых союзников. Полноэкранный вид показывает всю команду. Слова интерфейса не разбиваются по буквам; при нехватке ширины группа кнопок заголовка переносится целиком на следующую строку.
